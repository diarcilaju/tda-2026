# Trabajando en Nodejs
## Creando el proyecto
Vamos a crear el proyecto

```bash
npm init -y
```
Si ahora queremos trabajar con la sintaxis moderna ES Modules. Abrimos el archivo package.json y añadimos la propiedad type:

```javascript
"name": "clase6",
  "version": "1.0.0",
  "description": "",
  "type":"module",
  "main": "index.js",
```
